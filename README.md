# دفتري

تطبيق آيفون شخصي يرتّب اليوم: المواعيد والمهام والأفكار، مع تنبيهات بثلاث درجات (عادي، مهم، ضروري بمنبّه حقيقي)، ورسالة صباحية، ومراجعة مسائية «وش صار اليوم؟».

- مكتوب بـ SwiftUI، والحد الأدنى iOS 26.
- المشروع يتولد بـ XcodeGen من `project.yml`، ويبنيه GitHub Actions على أجهزة Mac.
- كل البيانات محفوظة في الجوال فقط.
